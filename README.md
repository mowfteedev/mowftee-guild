# ⚔️ mowftee-guild: Đội Ngũ AI Chuyên Gia Thực Chiến Cho Antigravity

> **Bang hội AI tinh nhuệ được may đo riêng cho Google Antigravity — Tinh gọn, thực dụng, 100% tiếng Việt, có kỷ luật thép và bộ nhớ dự án trường tồn.**

---

## 🚀 Triết Lý của mowftee-guild

Không giống như các thư viện AI cồng kềnh với hàng trăm vai trò xa lạ làm bạn bị "ngợp", **`mowftee-guild`** được thiết kế tinh xảo cho lập trình viên thực chiến:

1. **🎯 Tinh gọn & Đúng việc**: 10 vị trí then chốt, bao trọn 100% vòng đời phát triển phần mềm từ ý tưởng, kiến trúc, code, kiểm thử đến bàn giao.
2. **⚡ Tốc độ & Chuẩn hoá**: Tên gọi chuẩn ngành, gõ `@` siêu nhanh (`@tech-lead`, `@frontend`, `@backend`, `@tester`...).
3. **🧠 Bộ nhớ Dự án Bền vững (Project Memory)**: Giải quyết triệt để vấn đề "quên bối cảnh" của AI thông qua thư mục `.memory/` nằm ngay trong dự án.
4. **📜 Kịch bản Tác chiến Mẫu (Workflows)**: Có sẵn kịch bản mẫu điều phối 10 cao thủ chuyền bóng cho nhau mượt mà từ số 0 đến sản phẩm hoàn chỉnh.

| **`@backend`** | **Kiến Trúc Sư Máy Chủ** | Chuẩn hóa API Contract-First, chống gửi trùng đơn `Idempotency-Key`, Clean Architecture, không bao giờ trả lỗi trên HTTP 200. | Khi cần tạo endpoint, viết nghiệp vụ hệ thống, xử lý luồng dữ liệu. |

| **`@designer`** | **Kiến Trúc Sư Thiết Kế** | Xây dựng Design Tokens (bảng màu, lưới 8pt grid, typography), phân cấp thị giác 60-30-10, thiết kế 6 trạng thái vi tương tác. | Khi cần định hình giao diện đẹp mắt, nhất quán và sang trọng. |

| **`@devops`** | **Kỹ Sư Vận Hành** | Dockerfile đa tầng siêu nhẹ (<150MB) non-root, Docker Compose cô lập mạng nội bộ, Nginx SSL, CI/CD GitHub Actions không gián đoạn. | Khi cần đóng gói ứng dụng hoặc triển khai lên máy chủ VPS/Cloud. |

## ⚡ Bộ Lệnh Quản Trị `setup.sh`

Mở terminal trong thư mục `mowftee-guild`:

```bash
# 1. Cài đặt toàn bộ 10 chuyên gia vào Antigravity (1-Click)
./setup.sh install

# 2. Kiểm tra sức khỏe và tính toàn vẹn của 10 chuyên gia
./setup.sh check

# 3. Khởi tạo nhanh Bộ Nhớ Dự Án (.memory/) vào dự án của bạn
./setup.sh init /duong-dan-toi-du-an-cua-ban

# 4. Gỡ bỏ sạch sẽ khỏi Antigravity (khi không dùng nữa)
./setup.sh uninstall
```

> **Mẹo tạo lệnh tắt (Alias)**: Thêm dòng sau vào `~/.bashrc` để khởi tạo bộ nhớ bất kỳ lúc nào:
> ```bash
> echo "alias guild-init='/home/mowftee/Templates/mowftee-guild/setup.sh init .'" >> ~/.bashrc
> source ~/.bashrc
> ```

## 🏁 Quy Trình Khởi Động Dự Án Mới Thực Chiến (Từ A đến Z)

### Bước 0: Tạo thư mục & Nạp bộ nhớ (10 giây)
```bash
mkdir ~/du-an-moi && cd ~/du-an-moi
/home/mowftee/Templates/mowftee-guild/setup.sh init .
agy
```

### Bước 1: Gọi `@tech-lead` lên kiến trúc
```text
@tech-lead Tôi muốn xây dựng dự án [Tên Dự Án] với ý tưởng: [Mô tả chi tiết ý tưởng].
Hãy đọc .memory/, phân tích ranh giới nghiệp vụ, chọn Tech Stack và chia nhỏ task vào progress.md.
```

### Bước 2: Gọi `@database` & `@designer` chuẩn bị móng
```text
@database Thiết kế lược đồ PostgreSQL chuẩn 3NF, index khóa ngoại và partial index cho các trạng thái hay lọc.
@designer Xây dựng Design Tokens (mã màu, lưới 8pt, font chữ) và quy chuẩn giao diện cho @frontend.
```

### Bước 3: Triển khai `@backend` & `@frontend`
```text
@backend Triển khai API theo chuẩn Contract-First, có Idempotency-Key và endpoint /healthz.
@frontend Xây dựng UI chuẩn Mobile-First (375px+), bao bọc đủ 4 trạng thái (Loading, Empty, Error, Success).
```

### Bước 4: Kiểm soát chất lượng cùng `@code-reviewer`, `@security`, `@tester`
```text
@code-reviewer Soát xét code, bắt lỗi race conditions và gắn nhãn Blocker nếu có lỗi nguy hiểm.
@security Quét sạch nguy cơ lộ secret và kiểm tra phân quyền IDOR.
@tester Đóng vai Reality Checker thử phá hoại: Nhập dữ liệu quái dị, click đúp liên tục, ngắt mạng giữa chừng. Chỉ cấp chứng nhận khi hệ thống trụ vững.
```

### Bước 5: Đóng gói & Bàn giao cùng `@devops` & `@doc-writer`
```text
@devops Đóng gói Dockerfile đa tầng siêu nhẹ (<150MB) và docker-compose.yml cô lập mạng nội bộ.
@doc-writer Viết file README.md chuẩn 5 giây hiểu ngay, hướng dẫn cài 3 bước và đặc tả API có curl mẫu.
```

## 🧠 Cơ Chế Bộ Nhớ Dự Án (Project Memory)

Khi chạy `./setup.sh init .`, thư mục `.memory/` được tạo ra:

```text
du-an-cua-ban/
└── .memory/
    ├── architecture.md    # Quyết định kiến trúc & Tech Stack đã chọn
    ├── progress.md        # Nhật ký tiến độ: Đã xong, Đang làm, Việc tiếp theo
    └── adr/               # Biên bản lưu trữ các quyết định kỹ thuật quan trọng
```

- **Khi mở phiên chat mới**: Gõ `@tech-lead đọc .memory/ và cho biết hôm nay chúng ta làm tiếp việc gì`.
- **Trước khi tắt máy**: Bảo `@tech-lead cập nhật tiến độ vào .memory/progress.md`.
- **Lợi ích**: Không bao giờ bị mất ngữ cảnh giữa các phiên chat, không phụ thuộc vào trí nhớ tạm thời của AI.

## 💡 Mẹo Vàng Khi Sử Dụng Antigravity Với mowftee-guild

1. **Triệu hồi nhiều chuyên gia cùng lúc**:
   ```text
   @backend thiết kế API đơn hàng, và @frontend viết component Form tương ứng để gọi API đó.
   @code-reviewer và @security cùng thẩm định đoạn code này giúp tôi.
   ```
2. **Bỏ qua câu hỏi xác nhận phiền phức (Chế độ chạy mượt)**:
   Nếu bạn muốn Antigravity thực thi câu lệnh mà không hỏi đi hỏi lại từng thao tác:
   ```bash
   agy --dangerously-skip-permissions
   ```
   *(Chạy với đúng quyền hạn user hiện tại của bạn, thao tác cực kỳ nhanh và mượt mà).*
