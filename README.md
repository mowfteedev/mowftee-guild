# ⚔️ mowftee-guild

> 🛡️ Đội ngũ 10 đặc nhiệm AI tinh nhuệ được thiết kế cho Google Antigravity. Ý tưởng từ mô hình Agency Agents

---

## ⚡ Cài Đặt (Quick Start)

```bash
# 📥 Tải repository về máy
git clone https://github.com/mowfteedev/mowftee-guild.git
cd mowftee-guild

# 🚀 Cài đặt toàn bộ 10 chuyên gia vào Antigravity
./setup.sh install
```

---

## 🛠️ Quản Trị Hệ Thống (`setup.sh`)

```bash
./setup.sh install     # 📦 Cài đặt / cập nhật kỹ năng vào Antigravity
./setup.sh check       # 🔍 Kiểm tra tính toàn vẹn của các kỹ năng
./setup.sh uninstall   # 🧹 Gỡ bỏ hoàn toàn khỏi máy
./setup.sh init [path] # 🧠 Khởi tạo bộ nhớ dự án (.memory/) cho thư mục mới
```
