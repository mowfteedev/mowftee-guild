## 🚀 Giới Thiệu

`mowftee-guild` là bộ kỹ năng 10 chuyên gia công nghệ tinh nhuệ được thiết kế riêng cho **Google Antigravity (AGY)**:

- 🎯 **Đúng việc**: 10 vị trí cốt lõi bao trọn toàn bộ vòng đời phát triển phần mềm.
- ⚡ **Tiện lợi**: Triệu hồi tức thì bằng cú pháp `@<tên-chuyên-gia>` trong Antigravity.
- 🇻🇳 **100% Tiếng Việt**: Văn phong kỹ sư chuẩn mực, tư duy kỹ thuật thực chiến.
- 🛡️ **Kỷ luật thép**: Quy chuẩn chặt chẽ về clean code, bảo mật và nghiệm thu thực tế.

---

## ⚡ Cài Đặt (Quick Start)

Chạy lệnh sau để cài đặt toàn bộ chuyên gia vào Antigravity:

```bash
git clone https://github.com/mowfteedev/mowftee-guild.git
cd mowftee-guild
./setup.sh install
```

> Kỹ năng sẽ được nạp tự động vào `~/.gemini/config/skills/`. Bạn có thể mở Antigravity (`agy`) ở bất kỳ thư mục nào trên máy để sử dụng.

## 🏛️ Danh Sách 10 Chuyên Gia (The Roster)

| Chuyên gia | Vai trò | Lĩnh vực chuyên sâu |
| :--- | :--- | :--- |
| **`@tech-lead`** | 🏛️ Tech Lead | Kiến trúc hệ thống, phân rã nghiệp vụ, ADR, điều phối đội ngũ |
| **`@frontend`** | 🎨 Frontend Developer | UI Mobile-First, phản hồi <150ms, WCAG AA, Core Web Vitals |
| **`@backend`** | 🏗️ Backend Architect | API Contract-First, chống trùng lặp `Idempotency-Key`, Clean Architecture |
| **`@database`** | 🗄️ Database Specialist | Lược đồ 3NF, đánh Index tối ưu, xử lý N+1, truy vấn <20ms |
| **`@designer`** | 🎨 UI/UX Designer | Design Tokens, thang lưới 8pt grid, phân cấp thị giác, vi tương tác |
| **`@code-reviewer`** | 👁️ Code Reviewer | Quyền phủ quyết Veto, bắt 🔴 Blocker, rà soát nợ kỹ thuật và clean code |
| **`@tester`** | 🧐 Reality Checker | Kiểm thử phá hoại cực hạn, tự động hóa Playwright không sleep, nghiệm thu |
| **`@security`** | 🔐 AppSec Specialist | Rà soát OWASP Top 10, ngăn ngừa lộ secret, chống IDOR và Prompt Injection |
| **`@devops`** | ⚙️ DevOps Engineer | Docker đa tầng <150MB non-root, Docker Compose, Nginx SSL, CI/CD |
| **`@doc-writer`** | 📚 Technical Writer | Bàn giao dự án: README 5 giây, cài đặt 3 bước, API Docs có curl mẫu |

## 💡 Cách Sử Dụng Trong Antigravity

Trong phiên chat Antigravity, gõ `@` kèm tên chuyên gia:

```text
# Bắt đầu dự án hoặc tham vấn kiến trúc:
@tech-lead Hãy giúp tôi phân tích kiến trúc cho tính năng thanh toán.

# Thiết kế database & API:
@database Thiết kế bảng dữ liệu và đánh index cho module đơn hàng.
@backend Viết API tạo đơn hàng có hỗ trợ header Idempotency-Key.

# Xây dựng giao diện:
@frontend Dựng component giỏ hàng chuẩn Mobile-First, đầy đủ trạng thái loading/error.

# Kiểm định chất lượng & bảo mật:
@code-reviewer và @security Hãy rà soát lại đoạn mã này trước khi merge.
@tester Thử các kịch bản phá hoại dữ liệu biên để kiểm tra độ ổn định.

# Đóng gói & bàn giao:
@devops Viết Dockerfile đa tầng và docker-compose.yml cho ứng dụng.
@doc-writer Soạn thảo file README.md hướng dẫn cài đặt và tài liệu API.
```

## 🛠️ Quản Trị Hệ Thống (`setup.sh`)

```bash
./setup.sh install     # Cài đặt / cập nhật 10 kỹ năng vào Antigravity
./setup.sh check       # Kiểm tra trạng thái và tính toàn vẹn của guild
./setup.sh uninstall   # Gỡ bỏ toàn bộ khỏi máy
```
