# Chọn workflow

Đây là tài liệu Markdown để tham khảo hoặc yêu cầu trợ lý đọc khi làm việc. Script cài skill không đăng ký các file này thành lệnh của host.

Chọn phần liên quan theo quy mô công việc; một trợ lý thực hiện lần lượt được. Khi dùng workflow sửa lỗi, giữ bốn bước kiểm chứng và báo rõ phần chưa làm được. Đọc [nguyên tắc chung](../docs/protocol.md) về phạm vi, quyền và bằng chứng.

Kết quả có thể trả trong hội thoại. Chỉ chọn [mẫu ghi chú](../templates/memory/README.md) khi cần lưu; không cần điền đủ bộ hoặc thêm người duyệt.
